Time To Kill Explorer

Reads CSVs and JSON directly from baseline_next_tick/time_to_kill/ and draw_ticks_with_decision_tree_grouping/run_<id>/ (one folder per decision tree run, holding that run's time_to_kill/ draws alongside its significance.json for the expected-value comparison) — no build/generation step. Serve the postEvaluation folder over HTTP (e.g. python -m http.server 8000 run there, not in this subfolder) so relative fetches and directory listings work.

Expected vs. actual

E(k/N), E(equal) and E(weight) come from that run's significance.json (written by DrawTicksWithDecisionTreeGroupingPostEvaluation.exportSignificance()) for whichever run is currently selected below in the "Draw Ticks..." card — both cards always show the same run, so there's no separate run picker here. E(alternating) is derived on this page from the same per-leaf probabilities (see expectedAlternating in the page source for the derivation): the expected number of draws until first kill when draws alternate between the equal and weighted policies, under the same fixed-probability/with-replacement simplification the other estimators already make. Actual mean is this page's own empirically observed mean draws-to-kill for the strategy that most closely matches each estimator's sampling policy: E(k/N) ↔ uniform random, E(equal) ↔ unweighted leaf round-robin, E(weight) ↔ significance-weighted leaf sampling, E(alternating) ↔ alternating leaf sampling. Actual ÷ Expected below 1 (green) means the mutant was killed faster in practice than the estimator predicted; above 1 (red, shown once it exceeds 2×) means slower.

Compare two runs

Compares empirically observed draws-to-kill between two decision tree runs of the same run-scoped dataset (their run_<id>/time_to_kill/ folders under draw_ticks_with_decision_tree_grouping/), strategy by strategy. Ratio is Run B ÷ Run A mean — below 1 (green) means Run B killed faster on average; above 1 (red, shown once it exceeds 2×) means slower.

All runs — summary statistics

Aggregates every discovered run_<id>/ folder: for each mutant and strategy/estimator, the mean, median, and standard deviation across runs. Actual summarizes each run's empirical mean draws-to-kill (so "mean" here is the mean-of-means); Expected summarizes each run's E(…) estimator value, showing how much the theoretical prediction itself shifts as the decision tree changes from run to run.
