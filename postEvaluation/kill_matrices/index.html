How these numbers are worked out
Valid scenarios
All 196,608 starting scenarios, minus those where the unmutated autopilot already violates the oracle. A mutant counts as killed only in valid scenarios.
Oracles
Draws until one mutant is killed
Scenarios are drawn at random without replacement. With N valid scenarios and K that kill the mutant, the expected number of draws is (N + 1) / (K + 1). The percentiles are exact, from the hypergeometric distribution.
Draws until all mutants are killed
From simulated random orders of the valid scenarios: the draw at which the last killable mutant is killed.
Best order
A greedy set cover: repeatedly take the scenario that kills the most mutants not yet killed. The true minimum can only be smaller or equal.
Mutants killed per scenario
For each valid scenario, the number of mutants it kills, counting mutants with the same kill set separately. "% of mutants" refers to all mutants, AiPilot excluded; "% of killable mutants" to those killed in at least one valid scenario.
